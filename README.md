# Carolina Silva Vidal

Bilingual professional landing page built with Astro, Tailwind CSS and GSAP.

## Commands

`npm install` installs dependencies.

`npm run dev` starts the local preview.

`npm run build` generates the static production site in `dist/`.

## GitHub Pages

This project is configured for the public user-site repository `licsilvavidal-ui.github.io`. Push to `main` runs `.github/workflows/deploy.yml`, which builds the site and deploys `dist/` to GitHub Pages.
